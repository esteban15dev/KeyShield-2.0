Protocolos de Seguridad

KeyShield fue diseñado bajo un modelo de conocimiento cero. Aquí te explicamos exactamente qué protege tus datos y qué información existe en el sistema.

Cifrado y Protocolos

AES-256-CBC Cifrado estándar militar. Tus contraseñas se cifran en tu dispositivo antes de salir a internet.
PBKDF2 · 100,000 iteraciones · SHA-256 Tu contraseña maestra se convierte en una clave criptográfica con 100 mil iteraciones, haciéndola resistente a ataques de fuerza bruta.
Web Crypto API (cifrado local) Todo el cifrado y descifrado ocurre directamente en tu navegador. La clave nunca viaja por la red.
IV aleatorio por operación Cada cifrado genera un vector de inicialización único de 16 bytes, garantizando que dos contraseñas iguales produzcan resultados distintos.
HTTPS / TLS en tránsito Toda comunicación con el servidor está protegida por cifrado de transporte. Los datos viajan siempre encriptados.
Supabase · RLS (Row Level Security) Las reglas de base de datos garantizan que cada usuario solo puede acceder a sus propios registros, incluso a nivel de motor de base de datos.

Lo que los desarrolladores sí pueden ver

Correo electrónico Usado para autenticación e identificar tu cuenta.
Nombre de usuario El nombre visible que registraste en la plataforma.
Metadatos de actividad Fecha de creación de cuenta, última sesión y cantidad de registros guardados.
Nombres de servicios y URLs Los nombres de las plataformas (ej. "Netflix") y sus URLs se guardan sin cifrar como referencia visual.

Lo que nadie puede ver (ni nosotros)

Tu contraseña maestra Nunca se transmite ni almacena. Solo existe en tu sesión local y se usa para derivar la clave de cifrado.
Las contraseñas de tus cuentas Se almacenan como texto cifrado con AES-256. Sin tu contraseña maestra es matemáticamente imposible descifrarlas.
Notas personales El contenido de tus notas también viaja y se almacena cifrado con la misma clave derivada.
Clave criptográfica derivada La clave AES jamás abandona tu navegador. Se genera en memoria durante la sesión y se descarta al cerrar.
KeyShield sigue el modelo Zero-Knowledge: incluso si nuestra base de datos fuera comprometida, tus contraseñas permanecerían ilegibles sin tu clave maestra.
